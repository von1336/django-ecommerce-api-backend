# Платформа электронной коммерции (E-Commerce Backend API)

Полнофункциональная серверная платформа для интернет-магазина, разработанная на Django 5 и Django REST Framework. Проект демонстрирует промышленный уровень архитектуры: разделение на предметные модули, строгие атомарные транзакции с блокировкой строк при списании товаров (`select_for_update`), асинхронную обработку событий через Celery, кэширование в Redis и контейнеризацию в Docker.

## Архитектура проекта

```
django-ecommerce-api-backend/
├── manage.py
├── ecommerce/           # Глобальные настройки проекта, Celery, WSGI/ASGI
├── users/               # Модуль пользователей, профили, JWT/токен-аутентификация
├── catalog/             # Каталог: древовидные категории, товары, фильтры и поиск
├── cart/                # Корзина покупателя (сессионная и постоянная)
├── orders/              # Оформление заказов, управление статусами, транзакции
├── notifications/       # Асинхронные задачи Celery (email-уведомления, отчеты)
├── conftest.py          # Базовые фикстуры pytest
├── pytest.ini           # Конфигурация запуска тестов
├── Dockerfile           # Контейнер приложения
├── docker-compose.yml   # Запуск Django, PostgreSQL, Redis и Celery
├── requirements.txt     # Зависимости
└── .env.example         # Пример конфигурации окружения
```

## Функциональные возможности

- **Каталог продукции**: древовидная структура категорий без ограничения вложенности, товары со статусами, ценами, остатками на складе, гибкая фильтрация и полнотекстовый поиск.
- **Корзина покупок**: валидация актуального наличия остатков на складе при добавлении и обновлении количества позиций.
- **Оформление заказов и финансовая целостность**: атомарное создание заказа в блоке `transaction.atomic()` с блокировкой строк товаров (`select_for_update()`) для гарантированной защиты от оверселлинга и состояния гонки (Race Condition). Автоматический возврат остатков на склад при отмене заказа.
- **Асинхронные очереди (Celery + Redis)**: отправка писем с подтверждением заказа, уведомления о смене статусов доставки и периодическая генерация отчётов через Celery Beat.
- **Кэширование**: использование Redis для кэширования ресурсоёмких выборок каталога.
- **Административная панель**: полноценный интерфейс управления магазином на базе Django Admin.

## Эндпоинты API

### Пользователи и аутентификация
| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/auth/register/` | Регистрация нового покупателя |
| POST | `/api/auth/login/` | Авторизация и получение токена доступа |
| POST | `/api/auth/logout/` | Завершение сеанса и отзыв токена |
| GET | `/api/auth/profile/` | Просмотр профиля текущего пользователя |
| PUT | `/api/auth/profile/` | Обновление контактных данных профиля |

### Каталог: Категории
| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/categories/` | Дерево категорий каталога |
| GET | `/api/categories/{slug}/` | Детали категории и список привязанных товаров |

### Каталог: Товары
| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/products/` | Каталог товаров (поиск, фильтрация по цене и категории) |
| GET | `/api/products/{slug}/` | Детальная карточка товара |

### Корзина
| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/cart/` | Содержимое текущей корзины с подсчётом общей суммы |
| POST | `/api/cart/items/` | Добавление товара в корзину с проверкой остатка |
| PATCH | `/api/cart/items/{id}/` | Изменение количества товара |
| DELETE | `/api/cart/items/{id}/` | Удаление позиции из корзины |
| POST | `/api/cart/clear/` | Полная очистка корзины |

### Заказы
| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/orders/` | Список заказов авторизованного пользователя |
| POST | `/api/orders/` | Оформление заказа из текущей корзины (атомарно) |
| GET | `/api/orders/{id}/` | Детальная информация о заказе и товарах |
| POST | `/api/orders/{id}/cancel/` | Отмена заказа и автоматический возврат остатков на склад |

## Установка и запуск

### Локальный запуск

1. Создайте и активируйте виртуальное окружение:
```bash
python -m venv venv
venv\Scripts\activate     # Windows
source venv/bin/activate  # Linux/macOS
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Скопируйте и настройте конфигурацию:
```bash
copy .env.example .env
```

4. Запустите PostgreSQL и Redis.

5. Выполните миграции базы данных:
```bash
python manage.py migrate
```

6. Создайте учётную запись администратора:
```bash
python manage.py createsuperuser
```

7. Запустите сервер разработки:
```bash
python manage.py runserver
```

8. Запустите фоновые процессы Celery (в отдельных терминалах):
```bash
celery -A ecommerce worker --loglevel=info
celery -A ecommerce beat --loglevel=info
```

### Запуск через Docker Compose

Запуск всего приложения (Django, PostgreSQL, Redis, Celery Worker, Celery Beat) одной командой:

```bash
docker-compose up -d --build
```

Выполнение миграций внутри контейнера:
```bash
docker-compose exec web python manage.py migrate
```

Создание администратора в контейнере:
```bash
docker-compose exec web python manage.py createsuperuser
```

API доступно по адресу: `http://localhost:8000`  
Панель управления: `http://localhost:8000/admin/`

## Тестирование

Запуск набора автоматических тестов:

```bash
pytest
```

Тестовый набор проверяет сценарии регистрации, работу каталога, добавление в корзину и атомарность оформления заказов с проверкой остатков на складе.
